# Research

Audits, interviews, competitor work, market notes and source records.

- `sources/` — one ingestion record per imported batch; see `AGENTS.md`
- `competitors/` — one note per competitor, dated observations
- `audits/` — point-in-time analyses, each ending in its date

Research notes paraphrase by default. Quote only where the exact wording carries
the meaning, keep quotes short, and attribute them.
