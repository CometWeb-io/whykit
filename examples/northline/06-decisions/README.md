# Decisions

The index of material decisions lives in [[06-decisions/decision-log]]. One row per decision; the reasoning lives in the linked record.

A decision is material when reversing it would cost real work, when it commits the company publicly, or when someone six months from now would otherwise ask "why on earth is it like this?".

Review cadence: Product Lead, first Monday of each quarter. Next: 2026-10-06.
