# README visuals

`overview.svg` is an editable workflow diagram. It describes the evidence, decision and review flow; it is not an application screenshot.

`explorer-demo.gif` is the README animation. It is converted, without edits,
from `site/media/explorer-demo.mp4` (a real recording of the Explorer on the
synthetic `examples/northline` vault; see `site/media/README.md`) with ffmpeg:
10 fps, 880 px wide, a 96-colour palette with Bayer dithering. Regenerate it
from the MP4 whenever the recording changes.
