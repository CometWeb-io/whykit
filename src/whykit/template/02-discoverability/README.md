# Discoverability

How the company is found: search, answer engines, content and authority planning.

Keep measurement and interpretation apart. A ranking or visibility number is a
verified fact with a date and a tool attached; what it means for the strategy is
an interpretation, and it belongs in a different paragraph.

Dated snapshots belong in `reports/`, not here. This directory holds the plans
and the systems; the numbers they produced are evidence, filed by date.
