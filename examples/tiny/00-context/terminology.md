# Terminology

Shared definitions. Two documents using one word differently is the most common
way this repository starts lying.

Add a term when you catch two people meaning different things by it, and write
what it is *not* wherever a neighbouring term is easy to confuse it with.

## Metric definitions

Metrics need more than a name: a metric is its definition plus the tool that
produced it. The same word measured in two tools is two metrics.
