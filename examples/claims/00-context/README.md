# Context

Verified foundations every other workstream depends on. If something here is
wrong, everything built on it is wrong too, so this directory has the highest bar
for evidence in the repository.

## Canonical documents

- `company.md` — verified company profile and constraints
- `goals.md` — approved business goals
- `terminology.md` — shared definitions, so two documents mean the same thing
- `evidence-register.md` — source index for important claims

## What does not belong here

Recommendations, plans and hypotheses. They live in the workstream directories
until they are accepted, and then they become decisions in `06-decisions/`.
